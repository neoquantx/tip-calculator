# Tip Calculator

A small restaurant bill calculator. Enter the bill, choose a tip, and see the tip, the total, and the share for each person. It is one HTML file with its own CSS and JavaScript. Nothing else is required.

## Features

- Bill amount with dollars and cents
- Tip presets for 10%, 15%, 18%, and 20%, plus a custom percentage
- Preset buttons and the custom tip field stay in sync
- Split the total across 1 to 20 people, with plus and minus buttons
- Results update as you type
- Tip amount, total bill, and total per person, shown in US dollars with two decimal places
- Reset restores an empty bill, a 15% tip, and one person
- Invalid amounts, tip percentages, and people counts are rejected with a clear message. The page does not show `NaN` or `Infinity`

## How to run

No install, server, or internet connection is needed.

1. Open the `Challenge-1` folder.
2. Double-click `index.html`, or in a browser choose **File → Open** and select `index.html`.

On macOS you can also run this from the project folder:

```bash
open index.html
```

The calculator works in current versions of Chrome, Firefox, Safari, and Edge.
